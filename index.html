03 / CONEXIONES CON PROPÓSITO

El contexto que necesitas.

La app sigue siendo local. Cada integración se configura desde los ajustes de escritorio.

TikTok CONSULTA AUTORIZADA

Conecta tu propia cuenta mediante la autorización oficial para consultar el perfil, los vídeos públicos y sus contadores de rendimiento.

  • Perfil y seguidores
  • Vídeos y estadísticas
  • Etiquetas locales
Requiere credenciales de desarrollador y permisos habilitados por TikTok. No publica vídeos ni lee mensajes privados.

RAWG BIBLIOTECA OPCIONAL

Busca un juego por su nombre y selecciona una portada. También puedes crear fichas con tus propias imágenes sin configurar esta integración.

  • Búsqueda de juegos
  • Nombre y portada
  • API key propia
Los datos y las imágenes consultados mediante la integración proceden de RAWG ↗. Las valoraciones de audiencia son personales.
04 / SIN LETRA PEQUEÑA

Lo esencial,
antes de empezar.

¿Esta web es la aplicación?

No. Esta es la página informativa de Mikyoin Studio. La aplicación se ejecuta en el escritorio y esta web no permite acceder a los datos guardados en tu ordenador.

¿Necesito conectar TikTok para usarla?

No. Puedes planificar y organizar tu contenido sin conectar ninguna cuenta. TikTok solo es necesario para consultar datos reales de tu perfil y tus vídeos. Los ejemplos de la app se identifican como demo.

¿Se publican mis guiones o mis estadísticas?

La app no envía tu planificación a esta web ni a un servidor del proyecto. Las consultas a TikTok y RAWG se realizan con sus servicios; las portadas remotas también requieren conexión.

¿Puedo descargarla desde esta página?

Esta web presenta una herramienta de uso personal. No ofrece una descarga pública ni un registro de usuarios. Puedes contactar con el responsable del proyecto para consultar su disponibilidad.
